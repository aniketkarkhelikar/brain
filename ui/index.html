Brain check results

Memory evidence

How safe updates work

The audit keeps events as history. It corrects only a contradicted Current State line when the newer source quote, date, target line, and confidence all pass strict checks. Old text moves verbatim to that note’s Log. Unsupported or unclear claims stay in this review list. Actions are recorded in the append-only vault log.

Vault structure

What gets checked

Broken or ambiguous links, empty notes, orphans, and processed Inbox files. Structure checks are deterministic; memory review uses AI and exact evidence. The same combined check runs daily, and edits to Markdown trigger the local watcher.
